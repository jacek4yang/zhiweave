# Markdown 内嵌交互实验

最近更新：2026-07-30

## 目标

知织允许笔记携带可交互的学习实验，但笔记依然必须是普通、可复制、可版本化的 Markdown。交互能力使用版本化的声明式数据，由知织内置的受信任组件渲染；笔记不能执行 JavaScript、加载远程脚本、访问文件、读取密钥或自行发起网络请求。

这保证同一份笔记在三种环境中都可用：

1. 在知织中显示交互界面；
2. 在普通 Markdown 阅读器中显示完整 JSON 源码；
3. 在未来版本缺少对应组件或配置损坏时，降级为可读、可复制的 fenced code block。

## v1 语法

CommonMark fenced code block 的 info string 固定为 `zhiweave-lab`，正文是 UTF-8 JSON：

````markdown
```zhiweave-lab
{
  "schema": "zhiweave/lab@1",
  "kind": "uuid",
  "title": "UUID 结构实验室",
  "initialValue": "01890f9e-7b5a-7cc3-98c4-dc0c0c07398f"
}
```
````

机器可读规格位于 [`schemas/zhiweave-lab-v1.schema.json`](../schemas/zhiweave-lab-v1.schema.json)。运行时还执行相同的严格检查：顶层必须是对象、拒绝额外字段、标题为 1–80 个字符、UUID 必须是标准带连字符形式、单块源码不得超过 16 KB。

## UUID 结构实验室

首个受控组件提供：

- 输入和即时校验任意标准 UUID；
- 使用系统密码学随机源在本机生成 UUID v4；
- 五段十六进制结构、128 位/16 字节长度、版本与变体解释；
- UUID v4 的 122 位随机负载说明；
- UUID v7 前 48 位 Unix 毫秒时间解析；
- 可展开的 128 位视图，显式标出版本位 48–51 和变体位 64–65；
- 复制当前 UUID；
- 复制只会生成兼容声明式配置的 AI 提示词；
- 交互状态默认不写回 Markdown，避免仅仅点击或播放就污染正文与版本历史。

## 解析与渲染边界

```text
Markdown 原文
  → 识别精确 info string
  → 16 KB 上限
  → JSON.parse
  → schema / kind / 字段白名单 / 值域校验
  → 内置组件注册表
  → React 受控渲染
```

任何一步失败都进入显式错误卡片，并展示未经修改的原始 fenced block。未知 `schema` 或 `kind` 不会尝试猜测，也不会自动下载插件。

## 能力安全模型

v1 交互块具有零外部能力：

- 无 `eval`、`Function`、动态模块或内联 HTML；
- 无网络、文件系统、Shell、Tauri command、SQLite 或同步访问；
- 无剪贴板读取；只有用户点击按钮后才写入用户明确选择的文本；
- UUID 生成使用 `crypto.randomUUID()`，兼容路径使用 `crypto.getRandomValues()`；
- 配置不能指定 CSS、URL、事件处理器、组件路径或任意命令；
- React 默认文本转义仍然生效。

未来如果某类实验需要计时器、附件或网络，必须为每一种能力建立独立权限、可见提示、尺寸/频率上限和威胁模型；不能扩展为通用脚本沙箱。

## AI 协作

“复制 AI 生成提示词”只生成本机文本，不调用任何 AI 服务，也不上传笔记。提示词明确要求 AI 只返回受支持的 fenced block，且不得加入 HTML、JavaScript、网络请求或额外字段。返回内容仍要经过同一运行时校验，不因来自 AI 而获得信任。

## 扩展新实验类型的准入条件

每个新 `kind` 必须同时提交：

1. 版本化声明结构与 JSON Schema；
2. 严格解析器、字段数量和输入大小上限；
3. 无脚本的内置渲染组件；
4. 正常、边界、恶意和未知版本测试；
5. 窄屏、键盘、屏幕阅读器、实时分栏测试；
6. 失败降级和原文保真测试；
7. 对版本存储、导出、同步与 AI 提示词的兼容说明。

候选方向包括算法步进、状态流程动画、数据结构可视化、间隔复习测验和论文证据图。它们应作为小而明确的组件注册，而不是一个可以运行任意程序的平台。
