# UX 规格

最近更新：2026-07-30

## 工作台层级

桌面工作台从左到右为：

1. 48–52 px Activity Bar：一级模式切换。
2. 220–280 px 主侧栏：文件、搜索、收藏和最近项。
3. 弹性编辑器组：标签、分屏和正文。
4. 240–320 px 可折叠上下文栏：属性、反向链接、局部图谱。
5. 22–26 px 状态栏：保存、索引、同步、语言、行列和错误。

默认不同时展示所有面板。编辑器区域必须是最大且最稳定的视觉表面。

## 核心交互

- `Ctrl/Cmd+P`：快速打开。
- `Ctrl/Cmd+Shift+P`：命令面板。
- `Ctrl/Cmd+S`：立即保存当前缓冲。
- `Ctrl/Cmd+B`：切换主侧栏。
- `Ctrl/Cmd+\`：分屏。
- 阅读视图单击 Wiki 目标打开知识节点；Live Preview 使用 `Ctrl/Cmd+单击`，普通单击只移动
  编辑光标。
- 单击文件进入临时预览，编辑或双击后固定标签。
- 右键菜单只提供与当前对象相关的命令；同一命令在菜单、快捷键和命令面板共享一个 command id。
- 焦点、选中、Hover、错误和只读状态不能只依靠颜色。

## 编辑体验

- 输入期间不弹出阻塞式提示，不因装饰导致光标跳动。
- 自动保存状态只进入状态栏：`已保存`、`保存中`、`未保存`、`冲突`、`失败`。
- Live Preview 中光标离开语法范围时显示渲染结果，进入时显示原始 Markdown。
- 阅读预览使用语义 DOM，跨段选择和复制保持自然文本；“复制 Markdown 原文”保留源码，
  “复制结构化阅读文本”保留标题、任务层级、表格、代码、公式和脚注信息。
- 搜索、命令和 Quick Open 都支持键盘完成、Esc 关闭和焦点恢复。
- 危险操作显示精确对象和影响范围；覆盖、删除和恢复必须可撤销或有保护快照。

## 响应式

- ≤1100 px：默认隐藏右侧上下文栏。
- ≤720 px：进入移动信息架构，隐藏桌面导航，只保留当前任务和移动底部导航。
- Android 横屏：保留可折叠导航，不把桌面三个固定栏硬塞入视口。
- 触控目标不小于 44×44 CSS px；编辑器正文不小于 16 px，避免软键盘缩放。

## 可访问性

- 所有图标按钮必须有可翻译的 accessible name。
- 对话框具备 `role=dialog`、标题、焦点陷阱和打开前焦点恢复。
- 列表、树、标签和菜单采用对应语义与方向键模型。
- `prefers-reduced-motion` 下关闭非必要动画。
- 高对比主题不依赖半透明边框。

## 上下文菜单矩阵

- 标题栏：最小化、最大化/还原、关闭。
- Activity Bar/工作区空白：新建节点、今日日记、交互实验、侧栏。
- 笔记栏空白：以上命令加搜索；具体节点：打开、分栏、复制名称/学习提示词、版本图。
- 标签：打开、分栏、关闭当前/其他、重开关闭标签、节点版本。
- 编辑器：仅有选区时显示复制；撤销/重做按历史可用性启用；当前笔记保存、学习和视图命令。
- 原生输入框：仅显示选区剪切/复制、粘贴和全选。
- 阅读/实验块：当前节点保存、Markdown/阅读文本/学习提示词复制、阅读或实验相关视图与版本
  操作，不出现标签删除或窗口命令。
- 反向链接面板空白：关闭关系栏、切换大纲/实时语法及当前节点的复制、版本和视图命令；具体
  引用项：按引用来源节点显示打开、分栏、复制、重命名和版本命令，不继承面板空白菜单。
- 局部图谱空白：关闭图谱、切换反向链接/大纲/实时语法及当前节点的复制、版本和视图命令；
  具体图节点：显示该节点的打开、分栏、复制名称、重命名和版本命令，不继承图谱空白菜单。
- Wiki Link/嵌入：只显示“解析并打开目标”和“复制目标文本”；浏览器预览因没有原生索引只
  保留复制。missing/ambiguous 通过诊断说明原因，不显示不相关的预览、标签或窗口命令。
- 版本节点：恢复、复制该版本、打开所属节点、删除该精确版本。

所有危险命令必须显示精确对象并保留确认/保护快照。当前工作台使用类型化 command registry
统一按钮、快捷键、命令面板和右键菜单；菜单按目标分流并支持首项聚焦、方向键、Home/End、
Esc 关闭和焦点恢复。能力矩阵会在浏览器预览中隐藏原生文件/备份命令，并把当前不可用但相关
的命令显示为禁用状态。

## 当前基线

专业深色工作台、Activity Bar、折叠笔记栏、多标签、实时分栏、状态栏、自定义 Windows 标题栏、
上下文命令菜单、统一命令面板和容器级实验响应式布局已完成第一切片。命令面板支持中文、
关键词/别名和模糊子序列检索，键盘循环选择、执行、关闭及触发点恢复。指定九个视口没有页面
水平溢出；≤720 px 保留 48 px Activity Bar 并把分栏改为上下布局。移动底部导航、全局 44 px
触控目标、主题/密度、快捷键编辑器和跨全部复杂面板的完整焦点管理仍待完成。共享 AST 阅读
视图已在 1280×720 和 390×844 验证：表格/长源码只在自身容器横向滚动，页面与正文无水平
越界；窄屏右键菜单保持在视口内。

原生右侧检查器新增可关闭反向链接面板，并与大纲互斥，避免压缩正文两次。面板按来源稳定
节点分组，逐条显示 link/embed、行列与截断上下文；点击引用打开来源 Markdown 并定位到开头。
关系能力只在原生索引 ready 时出现，浏览器预览不生成演示反向链接。≤1100 px 时检查器覆盖
在编辑区右侧，宽度受视口约束，不制造页面级水平滚动。

同一检查器槽位已加入按需局部图谱：默认显示当前稳定节点的一跳关系，link/embed 用柔和但
可区分的线型，重复引用用线宽表达，中心/关联节点有明确焦点与悬停状态。鼠标和 Enter/Space
都可打开节点；图谱背景与具体 SVG 节点使用不同上下文。390×844 下图谱覆盖编辑区而不挤压
Activity Bar，画布自适应剩余高度、图例贴底、关闭按钮完整可见，页面宽度严格等于视口。

正向 Wiki 导航复用同一 Rust resolver：阅读按钮单击打开，编辑器 `Ctrl/Cmd+单击` 打开，
可选 heading 在目标加载后定位。目标缺失时不自动创建，多个同名节点时不猜测；右键菜单标题
显示 authored target，并只保留 Wiki 对象操作。
