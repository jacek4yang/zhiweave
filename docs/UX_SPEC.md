# UX 规格

最近更新：2026-07-30

## 工作台层级

桌面工作台从左到右为：

1. 48–52 px Activity Bar：一级模式切换。
2. 220–280 px 主侧栏：文件、搜索、收藏和最近项。
3. 弹性编辑器组：标签、分屏和正文。
4. 240–320 px 可折叠上下文栏：属性、反向链接、局部图谱。
5. 22–26 px 状态栏：保存、索引、同步、语言、行列和错误。

默认不同时展示所有面板。编辑器区域必须是最大且最稳定的视觉表面。

## 核心交互

- `Ctrl/Cmd+P`：快速打开。
- `Ctrl/Cmd+Shift+P`：命令面板。
- `Ctrl/Cmd+S`：立即保存当前缓冲。
- `Ctrl/Cmd+B`：切换主侧栏。
- `Ctrl/Cmd+\`：分屏。
- 单击文件进入临时预览，编辑或双击后固定标签。
- 右键菜单只提供与当前对象相关的命令；同一命令在菜单、快捷键和命令面板共享一个 command id。
- 焦点、选中、Hover、错误和只读状态不能只依靠颜色。

## 编辑体验

- 输入期间不弹出阻塞式提示，不因装饰导致光标跳动。
- 自动保存状态只进入状态栏：`已保存`、`保存中`、`未保存`、`冲突`、`失败`。
- Live Preview 中光标离开语法范围时显示渲染结果，进入时显示原始 Markdown。
- 搜索、命令和 Quick Open 都支持键盘完成、Esc 关闭和焦点恢复。
- 危险操作显示精确对象和影响范围；覆盖、删除和恢复必须可撤销或有保护快照。

## 响应式

- ≤1100 px：默认隐藏右侧上下文栏。
- ≤720 px：进入移动信息架构，隐藏桌面导航，只保留当前任务和移动底部导航。
- Android 横屏：保留可折叠导航，不把桌面三个固定栏硬塞入视口。
- 触控目标不小于 44×44 CSS px；编辑器正文不小于 16 px，避免软键盘缩放。

## 可访问性

- 所有图标按钮必须有可翻译的 accessible name。
- 对话框具备 `role=dialog`、标题、焦点陷阱和打开前焦点恢复。
- 列表、树、标签和菜单采用对应语义与方向键模型。
- `prefers-reduced-motion` 下关闭非必要动画。
- 高对比主题不依赖半透明边框。

## 上下文菜单矩阵

- 标题栏：最小化、最大化/还原、关闭。
- Activity Bar/工作区空白：新建节点、今日日记、交互实验、侧栏。
- 笔记栏空白：以上命令加搜索；具体节点：打开、分栏、复制名称/学习提示词、版本图。
- 标签：打开、分栏、关闭当前/其他、重开关闭标签、节点版本。
- 编辑器：仅有选区时显示复制；撤销/重做按历史可用性启用；当前笔记保存、学习和视图命令。
- 原生输入框：仅显示选区剪切/复制、粘贴和全选。
- 阅读/实验块：阅读或实验相关视图、学习与版本操作，不出现标签删除或窗口命令。
- 版本节点：恢复、复制该版本、打开所属节点、删除该精确版本。

所有危险命令必须显示精确对象并保留确认/保护快照。当前菜单已按目标分流，但 command registry 和完整键盘方向键模型仍待收敛。

## 当前基线

专业深色工作台、Activity Bar、折叠笔记栏、多标签、实时分栏、状态栏、自定义 Windows 标题栏和容器级实验响应式布局已完成第一切片。指定九个视口没有页面水平溢出；≤720 px 保留 48 px Activity Bar 并把分栏改为上下布局。移动底部导航、44 px 触控目标、命令面板、主题/密度和完整焦点管理仍待完成。
