# ZhiWeave 产品规格

状态：工作草案
最近更新：2026-07-30

## 1. 产品定义

ZhiWeave（知织）是一款离线优先、Markdown 原生、本地数据优先的专业知识与学习工作站。它服务于需要长期写作、研究、编程实验、语言学习和间隔复习的个人用户。桌面端负责深度编辑和知识组织，Android 端负责查阅、收集与碎片化复习；手机端不是桌面端的缩小复制。

## 2. 不可妥协的原则

- UTF-8 Markdown 文件是普通笔记正文的事实来源。
- 集合使用开放定义文件，Canvas 使用开放 JSON，附件保留原文件。
- SQLite 只保存可重建索引、关系、复习与同步状态，不是正文唯一副本。
- 同步由用户触发，服务端只保存端到端加密对象，冲突必须显式呈现。
- 普通 Markdown 和代码块永不自动执行。
- 不内置云端模型 API，不索要 API Key，不自动发送用户内容。
- 简单模式与高级模式共享同一数据模型。

## 3. 核心用户任务

1. 快速收集资料或疑问。
2. 将问题拆成可验证的知识节点。
3. 在 Markdown 中写出当前理解、来源、实验和反例。
4. 建立 Wiki Link、属性和有类型关系。
5. 从来源笔记生成可追溯复习卡。
6. 在移动端复习并把薄弱点送回桌面“今天”。
7. 使用 Prompt Composer 预览并复制最小必要上下文到外部 AI。
8. 通过文件、版本、备份和显式冲突长期保护真实数据。

## 4. 默认信息架构

首次启动只暴露五个入口：

1. 今天
2. 学习
3. 知识库
4. 复习
5. 收集箱

默认工作台由 Activity Bar、可折叠导航、编辑器区域和精简状态栏组成。统一命令面板与对象相关
右键菜单提供可发现的键盘/鼠标等价路径；不可用命令解释性禁用，原生专属能力不在浏览器预览中
冒充可用。文件树、反向链接、集合、Canvas、图谱、版本、Vim、自动化和查询语言渐进暴露。

## 5. Release Candidate 验收范围

RC 必须至少包含真实 Markdown 文件、原子保存、SQLite/FTS 索引、专业工作台、CodeMirror 编辑与 Live Preview、动态语言 Grammar、离线公式、Wiki Link、反向链接、搜索、集合基础、学习主题、英语学习切片、FSRS 复习切片、Prompt Composer、数据迁移、性能与安全报告、完整中文离线手册，以及 Windows/Linux/macOS/Android 构建矩阵。

只有真实实现且通过相应质量门的功能才能标记完成。静态页面、假按钮、Mock 数据、仅浏览器可运行或重启丢失的数据均不计入完成。

## 6. 当前版本诚实说明

`v0.1.1` 仍是 alpha 尖峰，不可用于唯一一份真实敏感数据。Windows 原生端已使用真实 Markdown、
冲突安全原子保存、隐藏稳定 ID、可重建 SQLite/FTS、文件 watcher/外部冲突中心，以及可校验的
内容寻址版本 DAG、命名检查点、保留预览和完整本机工作区备份/重启恢复；浏览器模式仍只是明确
标识的 UI 预览。尚无外部备份导入器、客户端密码加密同步、10,000 篇启动预算验证、跨设备恢复
演练或 Android 文件系统验收，因此不能称为 RC 或完整长期数据保证。
